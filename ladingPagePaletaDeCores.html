O problema

O processo manual custa tempo que o setor não tem.

Consulta veículo por veículo

Cada placa exige abrir o navegador, digitar os dados, esperar o carregamento, baixar PDF — manualmente. Em 55 veículos, isso vira uma tarde inteira.

Ofícios preenchidos à mão

Nome do condutor, matrícula, placa, data, velocidade — tudo copiado de um lado para o outro. Erro de digitação = advertência inválida juridicamente.

Zero rastreabilidade

Quando o RH pergunta "esse ofício foi enviado?", ninguém sabe. Sem histórico, sem status, sem trilha de auditoria.

Como funciona

Um pipeline, quatro estágios, zero intervenção manual.

Da notificação do rastreador ao ofício assinado em PDF — o sistema orquestra tudo internamente.

01

Recepção

Webhook recebe o alerta de excesso de velocidade enviado pela Wialon em tempo real.

02

Validação

Aplica a regra de tolerância e verifica o pico diário antes de considerar a infração.

03

Geração

Template HTML preenchido dinamicamente e renderizado em PDF oficial via Puppeteer.

04

Persistência

Arquivo salvo em disco e metadados gravados no SQLite local com status rastreável.

Stack
Electron · React + TypeScript · Node.js + Express · SQLite · Puppeteer · Tailwind CSS
A solução

Quatro módulos integrados, um único executável.

M1

Consulta DETRAN-CE automatizada

Playwright headless preenche placa e chassi, aguarda o resultado e captura o PDF gerado. Funciona com 1 veículo avulso ou lote completo.

single batch xlsx pdf auto
M2

Integração Wialon em tempo real

Webhook recebe os alertas de excesso de velocidade. Regra de consolidação por pico diário evita duplicar a mesma ocorrência várias vezes.

webhook pico diário tolerância
M3

Ofícios oficiais em PDF

Template institucional preenchido com dados do condutor, veículo, local e velocidade. Nomenclatura padronizada para arquivamento.

puppeteer template tailwind assinatura
M4

Dashboard com trilha de auditoria

Histórico completo com status por registro — registrado, gerado, enviado, ignorado ou erro — e filtros por período, placa e condutor.

histórico retenção auditoria

Roadmap

Desenvolvimento em cinco blocos incrementais.

Cada bloco é entregável e testável de ponta a ponta. O MVP roda antes do lote escalar.

BLOCO 01 Concluído

Setup da base e arquitetura

Estrutura de pastas (main / renderer / shared), aliases de importação, backend Express integrado ao Vite, migrações SQLite iniciais.

BLOCO 02 Em curso

Integração Wialon e Webhook engine

Schema do webhook, rota de recepção, enriquecimento de dados via API REST Wialon, camada de regras com tolerância de velocidade.

03
BLOCO 03

Template HTML e engine de impressão PDF

Layout responsivo do Ofício de Advertência em HTML/Tailwind, configuração do Puppeteer, salvamento automático em /documentos/oficios/.

04
BLOCO 04

Dashboard e interface de operação

Tabela de histórico com filtros, modal de 2ª via, tela de configurações, cards de indicadores operacionais.

05
BLOCO 05

Empacotamento desktop e finalização

Empacotamento Electron/Tauri, teste do fluxo completo em ambiente limpo, geração do .exe final.
