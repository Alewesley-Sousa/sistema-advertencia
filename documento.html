Gerador Automático de Ofícios de Advertência

Integração com API Wialon para automação de processos operacionais e gestão de frotas.

01. Visão Geral do Projeto

O objetivo do sistema é automatizar a emissão de Ofícios de Advertência por Excesso de Velocidade. O sistema receberá notificações de infrações em tempo real da plataforma Wialon, processará as regras de negócio, consultará dados complementares de veículos/condutores e gerará um documento PDF formatado de forma automática.

Público-Alvo

Operadores da frota e setor de Recursos Humanos / Transporte da empresa.

Modelo de Implantação

Aplicação local (Desktop/Executável .exe) com backend integrado e banco de dados embarcado.

03. Arquitetura e Stack Tecnológica

Frontend UI
  • React + TypeScript: Construção da interface do usuário (painel de controle, logs e histórico).
  • Tailwind CSS: Estilização ágil e responsiva das telas e dos templates de documentos.
Backend API
  • Node.js + TypeScript: Servidor HTTP para recepção de Webhooks da API do Wialon e gerenciamento das regras.
  • SQLite: Banco de dados relacional leve (baseado em arquivo único local), ideal para desktop.
  • Puppeteer / HTML-pdf: Renderização do template HTML/Tailwind em arquivos PDF oficiais.
Empacotamento EXE
  • Tauri (ou Electron): Para empacotar o backend Node.js e a interface React em um único arquivo executável (.exe).

05. Requisitos Funcionais

Recepção de Alertas

Expor um endpoint HTTP para receber os alertas de velocidade enviados pelo Wialon.

Processamento & Filtros

Identificar veículo, grupo (ex: grupo Force), velocidade registrada e limite da via. Aplicar regras de tolerância (ex: excesso acima de X% ou X km/h).
